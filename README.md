# Qedric James

**Senior Software Engineer · Full Stack · AI-Native Development · Web3**

I design and build production software across frontend, backend and application architecture, primarily using TypeScript, React, Next.js and NestJS.

A major focus of my current work is **AI-native software development**: designing the architecture, context and guardrails that allow AI agents to make reliable changes to real codebases. I also have deep experience in blockchain and Web3, including Solidity and EVM smart contracts, DeFi, NFTs, token standards, wallet integrations and protocol-aware user experiences.

## AI-native engineering

I’m particularly interested in how engineering teams move from simply using AI to building a dependable development system around it.

My work includes:

- Encoding architectural decisions and engineering standards for both developers and AI agents
- Designing reusable skills that give agents the context and procedures needed to work reliably
- Building guardrails around planning, implementation, testing and validation
- Creating workflows that let product and business teams run safe, bounded experiments through AI
- Shifting repeatable implementation work toward specification, orchestration, validation and review

The goal is to make AI-assisted development predictable, maintainable and accessible without weakening engineering standards.
